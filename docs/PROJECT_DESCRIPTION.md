TCL Guide — a local discovery platform for Tachileik, Myanmar, replacing scattered Telegram posts and social media with one browsable directory of food-related businesses.

What it has:

Map-first Places Explorer — the main screen. A full-screen map and a place list showing the same results in sync: tap a marker to highlight its list item, tap a list item to fly the map to its marker and open a preview card.
Search & filtering — search across names, categories, and areas, plus one-tap category chips (noodles, cafe, bakery, etc.). Filters live in the URL, so any filtered view is shareable and bookmarkable.
Mobile bottom sheet — on phones the list becomes a draggable sheet over the map: a peek view with a couple of places, expandable to the full list.
Place detail pages — photo gallery, category and area, address, phone, hours, price level and note, description, a mini location map, and an external maps link for directions.
Admin directory management — a dashboard with directory stats (total, published, areas covered), full place management (create, edit, publish/hide, delete), category management, a click-or-drag map picker for setting locations, and direct photo uploads.
Access control — public browsing needs no account; only admins (bootstrapped from a configured email) can add or change places.
